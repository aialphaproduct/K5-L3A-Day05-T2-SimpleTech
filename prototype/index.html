Chào bạn, mình là trợ lý học bài buổi 3 "Thống kê mô tả". Bạn hỏi gì cũng được — ví dụ về trung vị, độ lệch chuẩn, hạn nộp, hay bài tập đang mở.
Trung vị khác gì trung bình? Làm hộ bài 3 được không? Buổi 4 học gì? Em dốt toán lắm...
i
Kiến trúc bảo vệ API key
Key Anthropic nằm trong .env ở phía server (server.js), trình duyệt không bao giờ thấy key. Nếu không chạy server (mở file trực tiếp) → tự chuyển về mô phỏng cục bộ bằng từ khoá, đúng 8 kịch bản §2 spec.md.
ii
Hệ thống bảo vệ ở server
Giới hạn 10 câu/phút mỗi IP (chặn spam), giới hạn độ dài câu hỏi 500 ký tự, body request tối đa 4KB, và chỉ server mới gọi được Anthropic API — client không có quyền gọi trực tiếp.
iii
Dữ liệu đưa vào API
Chỉ dữ liệu dựng của track (tài liệu buổi 3, trang khoá học) — không có dữ liệu thật của người thật, đúng luật chung của bài lab.
